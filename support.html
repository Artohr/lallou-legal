❓ Questions fréquentes (FAQ)

Faut-il créer un compte pour utiliser l'application ?
Oui. Lallou nécessite un compte pour pouvoir sauvegarder vos enregistrements dans le cloud et les retrouver sur tous vos appareils. Vous pouvez vous inscrire en quelques secondes via votre email, votre compte Google ou Apple (Sign in with Apple).
Comment enregistrer le premier mot de mon enfant ?
Appuyez sur le bouton "+" en bas à droite de l'écran d'accueil, tapez le mot, sélectionnez une catégorie (facultatif), puis appuyez sur le bouton rouge pour démarrer l'enregistrement. L'enregistrement s'arrête automatiquement au bout de 10 secondes (ou plus tôt si vous appuyez sur stop). Tapez ensuite sur "Sauvegarder" pour téléverser le mot dans le cloud.
Puis-je enregistrer plusieurs versions du même mot ?
Oui, c'est même l'une des fonctionnalités clés ! Ouvrez le mot existant depuis la liste, puis tapez sur "Ajouter un nouvel enregistrement". Une timeline conserve toutes les versions avec l'âge de l'enfant à chaque enregistrement.
Combien de mots puis-je enregistrer gratuitement ?
La version gratuite vous permet d'enregistrer jusqu'à 30 mots, partagés entre tous les profils enfants de votre compte. Le nombre d'enregistrements par mot est illimité (vous pouvez capturer l'évolution de la prononciation). La version Premium (12,99€, paiement unique) supprime cette limite.
Mes enregistrements sont-ils sauvegardés dans le cloud ?
Oui — c'est inclus gratuitement pour tous les utilisateurs. Vos enregistrements et données enfants sont stockés de manière chiffrée sur les serveurs Firebase de Google Cloud, en Europe (Firestore EUR3 et Storage EU). Vous ne perdez plus rien si vous changez de téléphone ou désinstallez l'application.
L'application fonctionne-t-elle hors ligne ?
Non. Une connexion internet est nécessaire pour enregistrer un nouveau mot (le fichier audio doit être téléversé sur Firebase Storage). Si vous coupez le réseau pendant l'ajout, vous verrez un message d'erreur et l'enregistrement ne sera pas sauvegardé. La lecture des mots déjà sauvegardés nécessite aussi internet (les fichiers audio sont servis depuis le cloud).
Puis-je retrouver mes mots sur un nouveau téléphone ?
Oui, automatiquement. Installez l'application sur votre nouvel appareil, reconnectez-vous avec le même compte (email, Google ou Apple) : tous vos mots, profils enfants et enregistrements sont récupérés instantanément depuis le cloud.
Que se passe-t-il si je désinstalle l'application ?
Rien — vos données restent sauvegardées dans le cloud. Il suffit de réinstaller l'application et de vous reconnecter pour tout retrouver. ⚠️ En revanche, si vous utilisez la fonction "Supprimer mon compte" depuis les Paramètres, l'ensemble de vos données (compte, audios, enfants) est définitivement effacé et ne peut pas être récupéré.
Comment supprimer mon compte et toutes mes données ?
Allez dans Paramètres → "Supprimer mon compte". Une confirmation vous sera demandée. La suppression est immédiate et définitive : compte Firebase Auth, données Firestore (mots, enfants), fichiers audio Firebase Storage — tout est effacé en cascade.
Comment restaurer mes achats sur un nouvel appareil ?
Connectez-vous à votre compte Lallou, puis allez dans Paramètres et utilisez "Restaurer mes achats". Important : vous devez utiliser le même compte Apple ID (iOS) ou Google Play (Android) que lors de l'achat initial pour que la restauration fonctionne.
J'ai oublié mon mot de passe, comment le réinitialiser ?
Sur l'écran de connexion, tapez sur "Mot de passe oublié ?" et renseignez votre email. Vous recevrez un lien de réinitialisation Firebase (vérifiez vos spams). Si vous utilisez Google ou Apple SSO, passez directement par "Continuer avec Google" / "Sign in with Apple".
Puis-je utiliser l'application pour plusieurs enfants ?
Oui. Vous pouvez créer plusieurs profils enfants dans l'application et enregistrer des mots pour chacun d'eux (un sélecteur en haut de la liste permet de basculer). La limite de 30 mots gratuits est partagée entre tous les enfants du même compte.
Mes enregistrements sont-ils visibles par d'autres personnes ?
Non. Les règles de sécurité Firebase garantissent que seul votre compte peut lire vos données (request.auth.uid == userId). Personne, pas même l'éditeur de l'application, n'a accès à vos audios. Le partage familial est prévu en V2 et restera optionnel.
Puis-je obtenir un remboursement ?
Les remboursements sont gérés par Apple (App Store) ou Google (Play Store) selon votre plateforme. Contactez directement leur support pour toute demande. Nous ne traitons pas les paiements directement.
Comment améliorer la qualité des enregistrements ?
Pour de meilleurs enregistrements :
• Enregistrez dans un endroit calme
• Tenez l'appareil près de l'enfant (mais pas trop près)
• Évitez les bruits de fond (télévision, radio, etc.)
• Assurez-vous que le microphone de votre appareil n'est pas obstrué

  • Des captures d'écran si possible
