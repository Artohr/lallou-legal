3. Description du service

Lallou est une application mobile permettant aux parents d'enregistrer, organiser et conserver dans le temps les premiers mots prononcés par leurs enfants sous forme d'enregistrements audio synchronisés dans le cloud.

L'Application propose :

  • Version gratuite : jusqu'à 30 mots enregistrés (partagés entre tous les profils enfants du compte), avec un nombre illimité d'enregistrements par mot
  • Version Premium (12,99€, paiement unique) : nombre illimité de mots ; fonctionnalités à venir (partage familial, compilations audio, export, time capsule)
  • Sauvegarde cloud automatique et gratuite pour tous les utilisateurs (Firebase, serveurs Europe)
  • Synchronisation multi-appareils via le compte utilisateur
